# 仮想知財部（Virtual IP Department）

**AI駆動の4人制プロフェッショナル知的財産部門**

---

## 概要

仮想知財部は、4名の知財プロフェッショナルで構成されるAI知財チームです。
発明発掘から権利化、活用まで、あらゆる知財業務を一気通貫で対応します。

全成果物にクリティカルシンキング（RAPID レビュー）を適用し、
スキのない高品質な知財業務を実現します。

## 対応業務

### 特許関連
- **発明発掘** (`/ip-invent`) — 技術者との対話を通じた発明の体系的発掘
- **発明提案書** (`/ip-proposal`) — 発明内容の構造化と提案書の作成
- **明細書・請求項** (`/ip-draft`) — 特許明細書と請求項の起案
- **中間応答** (`/ip-respond`) — 拒絶理由通知への意見書・補正書作成

### 調査関連
- **先行技術調査** (`/ip-search`) — 出願前調査、特許性評価
- **クリアランス調査** (`/ip-search`) — FTO調査、侵害リスク評価
- **無効資料調査** (`/ip-search`) — 異議申立・無効審判の証拠収集

### 意匠・商標
- **意匠出願** (`/ip-design`) — 意匠登録出願（全体・部分・関連・画像意匠）
- **商標出願** (`/ip-trademark`) — 商標登録出願（文字・図形・非伝統的商標）

### 戦略
- **知財戦略** (`/ip-strategy`) — IPランドスケープ、ポートフォリオ分析
- **クリティカルレビュー** (`/ip-review`) — 成果物のRAPIDレビュー

## クリティカルシンキング: RAPID モデル

全成果物に対して、以下の5つの観点で批判的検証を実施します：

| 要素 | 検証内容 |
|------|---------|
| **R**isk（リスク） | 法的リスク、事業リスク、手続リスクの特定 |
| **A**ssumption（前提） | 技術的・法的・事業的前提の妥当性検証 |
| **P**erspective（視点） | 審査官・競合・裁判官・経営者の多角的視点 |
| **I**ncompleteness（網羅性） | 内容・手続・調査の漏れの確認 |
| **D**ependency（整合性） | 文書内・文書間・戦略との整合性の検証 |

## 使い方

### 1. システムプロンプトの適用
`SYSTEM_PROMPT.md` の内容をAIのシステムプロンプトとして設定します。

### 2. 業務の依頼
依頼内容を伝えると、適切なワークフローが自動的に起動されます。

**例:**
- 「新しい技術について発明発掘をしたい」 → 発明発掘セッション起動
- 「この発明の明細書を書いてほしい」 → 明細書作成ワークフロー起動
- 「拒絶理由通知が来たので対応したい」 → 中間応答ワークフロー起動
- 「この製品が他社特許に抵触しないか調べたい」 → クリアランス調査起動

### 3. チームとの対話
4名のメンバーがそれぞれの専門性を活かして協働します。
メンバー間のレビュー・議論が可視化され、多角的な検討が行われます。

---

## 注意事項

- AIによる出力は参考情報であり、正式な法的助言ではありません
- 実際の出願・応答では資格を有する弁理士・弁護士による確認を推奨します
- 特許調査はAIの知識に基づく概念的なものであり、専用DBでの網羅的調査が必要です
- 未公開の発明内容を入力する場合、情報管理に十分注意してください
