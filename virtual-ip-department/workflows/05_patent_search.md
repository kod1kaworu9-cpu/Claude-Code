# ワークフロー：特許調査（Patent Search）

## 概要
先行技術調査、クリアランス調査（FTO）、無効資料調査を体系的に実施するプロセス。

## 起動コマンド
`/ip-search`

## 担当メンバー
- **主担当**: 田中 健太（調査設計・実行・分析）
- **補助**: 山本 彩花（意匠・商標関連の調査）
- **戦略判断**: 高橋 誠一（調査結果に基づく意思決定）

---

## 調査タイプ別フロー

### A. 先行技術調査（出願前調査）

```
┌──────────────────────────────────────────────────┐
│ Step 1: 調査設計【田中】                             │
│  ├── 調査対象発明の構成要件分解                       │
│  │   ├── 必須構成要件の特定                          │
│  │   ├── 任意構成要件の特定                          │
│  │   └── 各要件のキーワード展開                      │
│  ├── 検索戦略の設計                                  │
│  │   ├── キーワード検索式                            │
│  │   │   ├── 同義語リスト                            │
│  │   │   ├── 上位語・下位語                          │
│  │   │   └── 技術的な代替表現                        │
│  │   ├── 分類検索                                    │
│  │   │   ├── IPC（国際特許分類）                     │
│  │   │   ├── FI（ファイルインデックス）               │
│  │   │   ├── Fターム                                │
│  │   │   └── CPC（共同特許分類）                     │
│  │   └── 組合せ検索式の構築                          │
│  └── 調査範囲の設定                                  │
│      ├── 対象期間                                    │
│      ├── 対象国（日本、米国、欧州、中国等）            │
│      └── 非特許文献の要否                            │
├──────────────────────────────────────────────────┤
│ Step 2: 調査実行【田中】                             │
│  ├── 第1次スクリーニング                             │
│  │   ├── 検索結果の概要確認（タイトル・要約）         │
│  │   ├── 明らかに無関係な文献の除外                   │
│  │   └── 要注意文献の抽出                            │
│  ├── 第2次スクリーニング                             │
│  │   ├── 請求項の精読                                │
│  │   ├── 図面の確認                                  │
│  │   └── 関連度の評価（A/B/C ランク）                │
│  └── 第3次スクリーニング（精読）                     │
│      ├── 明細書全文の精読                            │
│      ├── 構成要件との詳細対比                        │
│      └── 引用文献のチェーン調査                      │
├──────────────────────────────────────────────────┤
│ Step 3: 分析・評価【田中＋山本】                      │
│  ├── 対比表（クレームチャート）の作成                 │
│  │   ├── 各構成要件と文献記載の対応                   │
│  │   ├── 一致/相違の判断                             │
│  │   └── 相違点の重要度評価                          │
│  ├── 特許性の評価                                    │
│  │   ├── 新規性の評価                                │
│  │   ├── 進歩性の評価                                │
│  │   │   ├── 組合せの動機付けの有無                   │
│  │   │   ├── 阻害要因の有無                          │
│  │   │   └── 効果の予測可能性                        │
│  │   └── 総合判断                                    │
│  └── 山本：RAPIDレビュー（調査の網羅性検証）         │
├──────────────────────────────────────────────────┤
│ Step 4: 報告書作成・戦略提言【田中→高橋】             │
│  ├── 調査報告書の作成                                │
│  ├── 出願に向けた推奨事項                            │
│  │   ├── 請求項の方向性の提案                        │
│  │   ├── 回避すべき先行技術の特定                     │
│  │   └── 差別化ポイントの明確化                      │
│  └── 高橋による戦略判断                              │
│      └── 出願GO/NO-GOの最終決定                      │
└──────────────────────────────────────────────────┘
```

### B. クリアランス調査（FTO調査）

```
┌──────────────────────────────────────────────────┐
│ Step 1: 対象技術の特定【田中＋高橋】                  │
│  ├── 実施予定の技術・製品の詳細確認                   │
│  ├── 調査対象国の決定                                │
│  │   ├── 製造国                                      │
│  │   ├── 販売国                                      │
│  │   └── 輸出入経路国                                │
│  └── 技術要素の分解                                  │
├──────────────────────────────────────────────────┤
│ Step 2: 有効特許の網羅的抽出【田中】                  │
│  ├── 権利存続中の特許の検索                          │
│  ├── 出願中（未権利化）案件の確認                     │
│  ├── 関連する実用新案の確認                          │
│  └── 意匠権の確認【山本】                            │
├──────────────────────────────────────────────────┤
│ Step 3: 侵害リスク評価【田中】                        │
│  ├── クレームチャートの作成                          │
│  │   ├── 各構成要件と自社技術の対比                   │
│  │   ├── 文言侵害の検討                              │
│  │   ├── 均等侵害の検討（均等の5要件）               │
│  │   └── 間接侵害の検討                              │
│  ├── リスクレベルの評価                              │
│  │   ├── 高リスク（文言侵害の可能性大）               │
│  │   ├── 中リスク（均等侵害の可能性あり）             │
│  │   └── 低リスク（侵害の可能性は低い）               │
│  └── 山本：RAPIDレビュー（見落としリスクの検証）      │
├──────────────────────────────────────────────────┤
│ Step 4: 対応策の提案【田中＋高橋】                    │
│  ├── 回避設計の提案                                  │
│  │   ├── どの構成要件を変更すれば回避できるか         │
│  │   └── 回避設計の技術的実現可能性                   │
│  ├── 無効化の可能性評価                              │
│  │   ├── 無効資料の有無の簡易調査                     │
│  │   └── 無効審判の成功可能性                        │
│  ├── ライセンスの検討                                │
│  │   ├── ライセンス交渉の可能性                      │
│  │   └── クロスライセンスの材料                      │
│  └── 最終リスクマトリクスの作成                      │
└──────────────────────────────────────────────────┘
```

## 品質チェックリスト

### 調査設計
- [ ] 調査対象の技術要素は漏れなく分解されているか
- [ ] 検索式は十分な同義語・関連語を含んでいるか
- [ ] 適切な特許分類が使用されているか
- [ ] 対象国・対象期間は適切か
- [ ] 非特許文献の調査は考慮されているか

### 調査実行
- [ ] スクリーニングは適切な基準で行われたか
- [ ] ノイズ（無関係文献）は十分に除外されているか
- [ ] 重要文献の見落としはないか（引用チェーン確認）

### 分析・報告
- [ ] 対比表は正確に作成されているか
- [ ] 評価は客観的根拠に基づいているか
- [ ] 推奨事項は具体的かつ実行可能か
- [ ] 調査の限界・留保事項は適切に記載されているか
