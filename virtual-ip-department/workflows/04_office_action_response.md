# ワークフロー：中間応答（Office Action Response）

## 概要
特許庁からの拒絶理由通知に対して、意見書及び補正書を作成するプロセス。

## 起動コマンド
`/ip-respond`

## 担当メンバー
- **主担当**: 田中 健太（分析・意見書・補正書作成）
- **協力**: 佐藤 理恵（請求項補正の整合性確認）
- **レビュー**: 山本 彩花（RAPIDレビュー）
- **最終判断**: 高橋 誠一（権利範囲の戦略的判断）

## 意見書テンプレート

```
═══════════════════════════════════════════════
           意見書
═══════════════════════════════════════════════

【提出日】YYYY年MM月DD日
【あて先】特許庁審査官 殿
【事件の表示】特願YYYY-XXXXXX
【発明の名称】[発明の名称]

上記事件について、YYYY年MM月DD日付け拒絶理由通知に対し、
下記のとおり意見を述べます。

           記

1. 拒絶理由の要約
─────────────────
  本願は、[拒絶理由の要約]との理由で拒絶されております。
  引用文献として以下が提示されています。

  引用文献1: [文献番号・名称]
  引用文献2: [文献番号・名称]（進歩性の場合）

2. 本願発明の説明
─────────────────
  本願の請求項1に係る発明は、[本願発明の要約]です。

  本願発明の構成要件を分説すると以下のとおりです。
  (A) [構成要件A]
  (B) [構成要件B]
  (C) [構成要件C]

3. 引用発明について
─────────────────
  引用文献1には、[引用発明の内容]が記載されています。

  [審査官の認定に対する意見がある場合]
  なお、審査官殿は[審査官の認定]と認定されていますが、
  [反論]と考えます。

4. 本願発明と引用発明との対比
─────────────────
  本願発明と引用発明1を対比すると、以下の相違点があります。

  【一致点】
  [一致点の記述]

  【相違点1】
  本願発明: [本願の構成]
  引用発明: [引用の構成]

  【相違点2】
  本願発明: [本願の構成]
  引用発明: [引用の構成]

5. 進歩性について
─────────────────
  上記相違点に係る構成について、以下の理由から、
  当業者が容易に想到し得るものではないと主張いたします。

  (1) [動機付けの不存在 / 阻害要因 / 顕著な効果 等の主張]

  (2) [裏付けとなる技術的根拠・データ]

  (3) [審査基準・判例の引用（該当する場合）]

6. 結論
─────────────────
  以上のとおり、本願発明は引用文献に記載された発明に基づいて
  当業者が容易に発明をすることができたものではなく、
  特許法第29条第2項の規定に該当しないものと思料いたします。

  よって、本願は特許されるべきものと確信いたします。

                                         以上
═══════════════════════════════════════════════
```

## 拒絶理由タイプ別の対応指針

### 新規性欠如（29条1項）
```
対応方針:
1. 引用発明の認定を精査（審査官の認定が妥当か）
2. 相違点の存在を主張（構成要件の対比を精密に）
3. 上位概念での一致でも下位概念では相違する点を主張
4. 必要に応じて限定補正

注意点:
- 進歩性に比べて争いにくいため、補正での対応が有効なことが多い
- 新規性否定のための引用は1文献限定であることを確認
```

### 進歩性欠如（29条2項）
```
対応方針:
1. 動機付けの不存在を主張
   - 技術分野の違い
   - 課題の違い
   - 作用・機能の違い
2. 阻害要因の存在を主張
3. 顕著な効果を主張
4. 組合せの困難性を主張

注意点:
- 審査官の論理構成（組合せの動機付け）を正確に理解する
- 反論は具体的かつ技術的根拠に基づく
- 後知恵（hindsight）に基づく論理には明確に反論
```

### 記載要件違反（36条）
```
対応方針:
1. 明確性違反：請求項の表現を修正
2. サポート要件違反：明細書の記載を示して反論、または請求項を限定
3. 実施可能要件違反：技術常識を主張、または実施例を補充

注意点:
- 補正は明細書の範囲内で行うこと（新規事項追加に注意）
- 用語の定義を明確にする補正が有効
```

## 品質チェックリスト

### 意見書
- [ ] 拒絶理由の種類を正確に特定しているか
- [ ] 本願発明の構成要件は正確に分説されているか
- [ ] 引用発明の認定は正確か
- [ ] 相違点の主張は明確で具体的か
- [ ] 反論の論理は一貫性があり説得力があるか
- [ ] 審査基準・判例の引用は適切か
- [ ] 文書全体のトーンは適切か（攻撃的すぎないか）

### 補正書
- [ ] 補正後の請求項は明細書にサポートされているか
- [ ] 新規事項が追加されていないか
- [ ] 補正の根拠（段落番号等）が明示されているか
- [ ] 補正後の権利範囲は事業保護に十分か
- [ ] 禁反言（prosecution history estoppel）のリスクは許容範囲か
