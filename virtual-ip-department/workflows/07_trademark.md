# ワークフロー：商標出願（Trademark Application）

## 概要
ブランド名、ロゴ、その他の識別標識を商標権により保護するプロセス。

## 起動コマンド
`/ip-trademark`

## 担当メンバー
- **主担当**: 山本 彩花（商標出願全般）
- **調査補助**: 田中 健太（先行商標調査の補助）
- **戦略**: 高橋 誠一（ブランド戦略との整合）

## 商標類否判断の基準

```
【類否判断の三要素】

1. 称呼（読み方）の類否
   ├── 音数の比較
   ├── 母音・子音の共通性
   ├── アクセントの位置
   └── 全体的な音感の類似性

2. 外観（見た目）の類否
   ├── 文字の構成
   ├── 書体・デザイン
   ├── 図形の類似性
   └── 全体的な印象

3. 観念（意味）の類否
   ├── 直接的な意味の共通性
   ├── 暗示・連想の共通性
   └── 特定の概念との結びつき

【判断方法】
- 三要素を総合的に判断（一要素の類似でも非類似の場合あり）
- 取引の実情を考慮
- 需要者の立場から判断
- 出所混同のおそれがあるか
```

## 品質チェックリスト

### 商標出願
- [ ] 商標の態様は識別力を有するか
- [ ] 商品・役務との関係で記述的でないか
- [ ] 公序良俗に反しないか（4条1項7号）
- [ ] 他人の氏名・名称を含んでいないか（4条1項8号）
- [ ] 先行商標との類似リスクは評価済みか
- [ ] 指定商品・役務は過不足なく選定されているか
- [ ] 類似群コードの確認は完了しているか
- [ ] 出願前の使用証拠は保全されているか（3条2項の場合）
- [ ] マドプロ出願の要否は検討したか
