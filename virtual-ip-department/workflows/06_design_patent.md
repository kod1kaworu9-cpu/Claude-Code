# ワークフロー：意匠出願（Design Patent/Registration）

## 概要
製品デザインの意匠権による保護を目的とした、意匠登録出願のプロセス。

## 起動コマンド
`/ip-design`

## 担当メンバー
- **主担当**: 山本 彩花（意匠出願全般）
- **補助**: 佐藤 理恵（図面の技術的正確性確認）
- **調査**: 田中 健太（先行意匠調査）
- **戦略**: 高橋 誠一（意匠ポートフォリオ戦略）

---

## 意匠出願戦略マトリクス

```
【保護対象の選択】

                    デザインの独自性
                    低い ←──────→ 高い
                 ┌────────┬────────┐
  影響範囲  大 │ 部分意匠  │ 全体意匠 │
  （需要者    │ ＋       │ ＋       │
   への訴求） │ 関連意匠  │ 関連意匠  │
              ├────────┼────────┤
          小 │ 部分意匠  │ 全体意匠  │
              │（要部に  │（単独で  │
              │ 絞る）   │ 十分）   │
              └────────┴────────┘

【関連意匠戦略】
本意匠（基本デザイン）
  ├── 関連意匠1（色違い）
  ├── 関連意匠2（サイズ違い）
  ├── 関連意匠3（細部の変形）
  └── 関連意匠4（派生デザイン）
```

## 品質チェックリスト

### 意匠出願
- [ ] 意匠に係る物品は物品区分表に適合しているか
- [ ] 6面図＋斜視図は揃っているか
- [ ] 各図面間の整合性は取れているか（同一物品として認識できるか）
- [ ] 部分意匠の場合、実線と破線の使い分けは適切か
- [ ] 新規性喪失の例外適用が必要ないか（公開済みの場合）
- [ ] 関連意匠の場合、本意匠との類似性は確保されているか
- [ ] 秘密意匠の要否は検討したか
- [ ] 意匠の説明は必要十分か

### 画像意匠（該当する場合）
- [ ] 画像の用途は明確か
- [ ] 操作画像か表示画像かの区分は適切か
- [ ] 画面遷移がある場合、変化状態図は用意されているか
