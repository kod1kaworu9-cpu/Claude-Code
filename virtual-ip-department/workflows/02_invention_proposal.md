# ワークフロー：発明提案書作成（Invention Proposal）

## 概要
発掘された発明を、特許出願に向けた発明提案書としてまとめるプロセス。

## 起動コマンド
`/ip-proposal`

## 担当メンバー
- **主担当**: 佐藤 理恵（作成）
- **レビュー**: 高橋 誠一（戦略的観点） + 山本 彩花（RAPIDレビュー）

---

## 実行フロー

```
┌──────────────────────────────────────────────────┐
│ Step 1: 情報収集・整理【佐藤】                       │
│  ├── 発明発掘会議の結果確認                          │
│  ├── 追加ヒアリング（必要に応じて）                   │
│  ├── 関連技術資料の収集                              │
│  └── 従来技術の整理                                  │
├──────────────────────────────────────────────────┤
│ Step 2: 発明の構造化【佐藤】                         │
│  ├── 発明の本質（核心的構成要件）の特定               │
│  ├── 課題と解決手段の対応関係整理                     │
│  ├── 上位概念 → 中位概念 → 下位概念の階層構築        │
│  ├── 効果の整理（主効果・副次的効果）                 │
│  └── 実施形態のバリエーション検討                     │
├──────────────────────────────────────────────────┤
│ Step 3: 提案書ドラフト作成【佐藤】                    │
│  ├── テンプレートに沿った記述                        │
│  ├── 図面の構成検討                                  │
│  ├── 請求項の骨子（プレクレーム）の作成               │
│  └── セルフレビュー                                  │
├──────────────────────────────────────────────────┤
│ Step 4: クリティカルレビュー【山本＋高橋】             │
│  ├── 山本：RAPIDレビュー実施                         │
│  ├── 高橋：戦略的観点からのレビュー                   │
│  └── レビュー指摘事項の取りまとめ                     │
├──────────────────────────────────────────────────┤
│ Step 5: 修正・最終化【佐藤】                         │
│  ├── レビュー指摘事項への対応                        │
│  ├── 最終版の作成                                    │
│  └── 次工程（明細書作成 or 先行技術調査）への引継ぎ    │
└──────────────────────────────────────────────────┘
```

## 品質チェックポイント

### 佐藤のセルフチェック
- [ ] 発明の本質は正確に捉えられているか
- [ ] 上位概念化は十分に行われているか（広すぎず狭すぎず）
- [ ] 課題と解決手段の対応は明確か
- [ ] 実施形態は複数のバリエーションを含んでいるか
- [ ] 図面で説明すべき内容は明確か
- [ ] 請求項の骨子は出願の方向性を示せているか

### 山本のRAPIDレビュー観点
- [ ] Risk: この発明提案に潜在的なリスクはないか
- [ ] Assumption: 技術的な前提に誤りはないか
- [ ] Perspective: 審査官・競合の視点で見て弱点はないか
- [ ] Incompleteness: 記載すべき事項の漏れはないか
- [ ] Dependency: 他の出願や事業計画との整合性

### 高橋の戦略的レビュー観点
- [ ] ポートフォリオ全体での位置づけは適切か
- [ ] 出願の優先度判断は妥当か
- [ ] 競合を意識した権利戦略になっているか
