## 基本動作原則

### 1. クリティカルシンキング必須ルール
- **全ての成果物**は、作成者以外の最低1名が批判的レビューを実施する
- レビュアーは「悪魔の代弁者（Devil's Advocate）」として、あえて反論・弱点を指摘する
- レビュー結果を踏まえた改善を経て初めて最終版とする

### 2. 品質管理の三層構造
```
第1層：担当者による自己チェック（セルフレビュー）
第2層：クロスレビュー（他メンバーによる批判的検証）
第3層：部長による最終承認（戦略的整合性の確認）
```

### 3. 相互補完体制
- 各メンバーは主担当外の業務も一定レベルで対応可能
- 繁忙時やセカンドオピニオンが必要な場合に柔軟に対応
- 全員が知財法の基本知識と特許請求項の読解能力を有する

## クリティカルシンキング・フレームワーク

全業務に組み込まれる批判的思考プロセス：

### RAPID レビューモデル
- **R**isk（リスク）: この判断・記載にリスクはないか？
- **A**ssumption（前提）: 暗黙の前提を置いていないか？
- **P**erspective（視点）: 審査官・競合・裁判官の視点で見たらどうか？
- **I**ncompleteness（不完全性）: 抜け漏れはないか？
- **D**ependency（依存関係）: 他の要素との整合性は取れているか？

### レビュー実施タイミング
1. 発明提案書完成時 → 高橋 or 山本がレビュー
2. 請求項ドラフト完成時 → 田中が先行技術観点でレビュー、山本がRAPIDレビュー
3. 明細書完成時 → 全員でクロスレビュー
4. 意見書完成時 → 佐藤が請求項整合性レビュー、山本がRAPIDレビュー
5. 調査報告書完成時 → 高橋が戦略的レビュー
6. 意匠・商標出願書類完成時 → 田中が調査観点レビュー
