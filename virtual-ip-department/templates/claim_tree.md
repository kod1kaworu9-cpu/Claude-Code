# 請求項ツリーテンプレート

## 使用方法
請求項の構造を視覚的に設計し、戦略的な従属関係を構築するためのテンプレート。

---

```

【請求項1】（独立項・最広）
  [構成要件A] と

  [構成要件C] と

  ├── 【請求項2】（従属項 → 請求項1）

  │
```

## 設計チェックリスト

### 独立請求項
- [ ] 必要最小限の構成要件で記載されているか
- [ ] 不要な限定が含まれていないか
- [ ] 回避困難な表現になっているか
- [ ] 複数カテゴリーが検討されているか

### 従属請求項ツリー
- [ ] 段階的に限定が加わる構造になっているか
- [ ] 各実施形態の重要な特徴をカバーしているか
- [ ] フォールバックポジションが確保されているか
- [ ] 分割出願のシードが埋め込まれているか
- [ ] 侵害立証が容易な具体的構成が含まれているか

### 戦略的考慮
- [ ] 独立請求項を補正で限定する場合の候補は十分か
- [ ] 競合の製品をカバーできる請求項があるか
- [ ] 将来の技術発展にも対応できる余地があるか
